# Dataset Information

## Source & Download
- **Kaggle Dataset:** [Credit Card Fraud Detection Dataset 2020](https://www.kaggle.com/datasets/kartik2112/fraud-detection)
- **Files:**
  - `fraudTest.csv` (555,720 rows, ~143 MB)
  - `fraudTrain.csv` (1,296,675 rows, ~335 MB)

## Simulated Data Note
> **Note:** This dataset consists of **simulated** credit card transactions generated using the open-source **Sparkov Data Generation** tool by Brandon Harris. It models synthetic customer profiles, merchant categories, geographic coordinates, and fraudulent transaction patterns across US credit cards. No real consumer cardholder data (PII) is contained in this dataset.

## Setup
Place `fraudTest.csv` (and `fraudTrain.csv` if training on the full corpus) inside this directory:
```
data/
├── README.md
├── fraudTest.csv
└── fraudTrain.csv (optional)
```
